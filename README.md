
# Fall Detection with Pose Detection

This repository implements fall detection using pose estimation models from [Ultralytics](https://www.ultralytics.com/). It's designed as a component of the [Guided Tour Companion Drone](https://github.com/NafieAlhilaly/guided-tour-companion-drone) project.

## Overview

Uses YOLOv8 pose detection models to detect human poses and identify fall events in real-time video streams or images.

## Features

- Real-time pose detection
- Fall detection algorithm
- Integration with Ultralytics YOLOv8
- Support for video and image inputs

## Project Integration

This module is part of the [Guided Tour Companion Drone](https://github.com/NafieAlhilaly/guided-tour-companion-drone) project.
